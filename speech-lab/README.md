# 端末内の音声 試作（speech-lab）

車ナビ試作の本体とは別のページです。本体（`../index.html` など）は使いません。

- アドレス：https://hideki0629-star.github.io/car-navi-prototype/speech-lab/
- 状態：試作（Claude Code 作成、2026-10-30）。レビュー前。Owner未承認。
- 今日の目的：iPhoneのSafariで、読み上げの音が出るかを確かめる。

## 使い方

1. ページを開いて「開始」を一度だけ押す（iPhoneのSafariは、画面に一度触れないとマイクも音も使えないため）。
2. 読み上げ → 聞き取り の順に準備する（初回は合計 約300 MB を読み込む）。
3. 準備ができたら、聞き取りはずっと続く。話している途中から文字が出る。
4. ボタンは3つ。
   - 確認音を鳴らす：モデルを使わずに「ピッ」と鳴らす。iPhone から音が出るかだけを確かめる（切り分け用）。
   - 「福岡駅まで案内します」を読み上げる：固定の文（切り分け用。残しておく）。
   - 聞き取った文字を読み上げる：最後に確定した文字を、そのまま読み上げる。
5. 記録欄に出るもの：読み上げの開始と終了の時刻、モデルのダウンロード量と読み込みにかかった時間、エラーの全文、話し始めから最初の文字が出るまでの時間。

## 条件と、その守り方

| 条件 | 守り方 |
|---|---|
| 外部のAPIやサービスを使わない | 部品とモデルは、このページと同じ場所から読み込む。CDNも使わない。**例外**：読み上げの声のモデルだけは、配布元（Hugging Face）から自動でダウンロードする（Owner判断、2026-10-30）。送るのはダウンロードの要求だけ |
| 音声を端末の外に送らない | 計算はすべてブラウザの中（WebAssembly）で行う。Content-Security-Policy で、通信先を自分の公開ページと配布元（`huggingface.co`・`*.hf.co`）だけに限っている。インラインのスクリプトは import map（ハッシュで指定）だけを許している |
| 日本語に対応 | 聞き取りは日本語専用のモデル（ReazonSpeech）、読み上げは日本語に対応した piper-plus と声のモデル（つくよみちゃん）|
| iPhoneのSafariで動く | WebAssembly の SIMD が必要（iOS 16.4 以降の見込み）。実機で確かめる |
| つくよみちゃんの声は試験用で、公開しない | 声のモデルはこのリポジトリに置かない（`.gitignore` で `*.onnx` を除外）。公開前に、利用条件と商用利用の可否を Owner が相談する |

## 前の版で読み上げの音が出なかった原因（2026-10-30）

記録欄に出ていたエラー（パソコンで同じ条件を作って再現した全文）：

```
【エラー】読み上げ：Error：声のモデルがまだありません。「声のモデルを選ぶ」で2つのファイルを選んでください
```

原因：前の版は、声のモデルを利用者に選んでもらう作りだった。選ばずに「読み上げの試験」を押すと、声を作る前に止まり、音を出す処理まで進まなかった。
直し方：声のモデルを配布元から自動で読み込むようにし、選択欄をなくした。あわせて、モデルを使わない確認音のボタンを足した。

## 聞き取り（ストリーミング表示）

- 画面側（`lab.js`）がマイクの音を 16000 Hz にして、約85ミリ秒ごとに Web Worker（`asr-worker.js`）へ流し込む。
- Worker で音声区間の検出（silero-vad）と音声認識（reazonspeech-k2-v2）を行う。計算を Worker に分けているので、計算の間もマイクの取り込みは止まらない。
- **ストリーミングについて**：sherpa-onnx には、日本語のストリーミング用モデルと、その WebAssembly 版が無い（日本語は話し終わってから認識する方式のモデルだけ）。
  そこで、話している間は「話し始めから今まで」の音を約0.4秒ごとに認識し直して、途中の文字を出している（計算が遅ければ間隔を自動で広げる）。
  話し終わったら（0.5秒の無音）、区間全体を認識して最終の文字にする。そのあとも聞き続ける。
- 読み上げや確認音を鳴らしている間は聞き取りを休み、鳴り終わって0.3秒後に再開する（自分の声を聞き取らないため）。
- 「話し始めから最初の文字が出るまで」は、声を検出した時刻から、VAD が声とみなすまでの時間（0.28秒）を引いた時刻を「話し始め」として数えている。
- 区間の前後に余白（前 0.8秒・後 0.3秒）を足して認識している。VAD が切り出した区間をそのまま渡すと、言葉の頭を取りこぼした。
- アドレスの末尾に `?raw=1` を付けると、ブラウザによる音の加工（エコー除去・雑音抑制・音量の自動調整）を切って比べられる。

## 読み上げ

- 声のモデル：つくよみちゃん（`tsukuyomi-chan-6lang-fp16.onnx` 39.7 MB と `config.json` 6.9 KB）。
  - 配布元：Hugging Face の ayousanz/piper-plus-tsukuyomi-chan。版をコミット `93c1fb6d67c29accc9ddf52326bb4582b1b52a3d` に固定している。
  - 読み込んだら大きさと SHA-256 を確かめる（モデルは配布元が公表している値、設定ファイルは手元で計算した値）。
  - 2回目からは、端末のキャッシュ（Cache Storage）から読む。
  - ライセンス：つくよみちゃんコーパス（CV.夢前黎）の利用規約に従う。公開前に Owner が相談する。
- piper-plus は声のモデルを「http(s) のアドレス」で受け取るため、ページの中で仮のアドレス（`local-tts-model/tsukuyomi.onnx`）を作り、
  そのアドレスへの読み込みだけを、読み込み済みのモデルにつなぎかえている。
- 再生は、マイクと同じ AudioContext を使う（「開始」の押下の中で作って動かしておく）。作った音の大きさ（最大・平均）も記録に出すので、
  音が聞こえないとき、声が作れていないのか（ほぼ無音）、再生されていないのかを見分けられる。

## 使っているもの

| もの | 版 | ライセンス | ダウンロード量 |
|---|---|---|---|
| sherpa-onnx（WebAssembly版、VAD＋音声認識）| 1.12.0（`sherpa-onnx-wasm-simd-1.12.0-vad-asr-ja-zipformer_reazonspeech`）| Apache-2.0（`licenses/sherpa-onnx-LICENSE.txt`）| 本体 wasm 11.5 MB |
| 音声認識モデル reazonspeech-k2-v2 | 上に同梱 | Apache-2.0（Hugging Face の reazon-research/reazonspeech-k2-v2 のモデルカードによる）| 171.0 MB（`.data`、VAD を含む）|
| 音声区間の検出 silero-vad | 上に同梱 | MIT（`licenses/silero-vad-LICENSE.txt`）| 上に含む |
| piper-plus（読み上げ）| 0.8.2（npm）| MIT（`vendor/piper-plus/LICENSE.md`、`THIRD-PARTY-LICENSES.md`）| 日本語の辞書入りの G2P wasm 60.1 MB ＋ JS |
| @piper-plus/g2p | 0.4.2（npm）| MIT（`vendor/piper-plus-g2p/LICENSE.md`）| 小さい |
| onnxruntime-web | 1.30.0（npm）| MIT（`licenses/onnxruntime-LICENSE.txt`）| wasm 14.2 MB |
| 声のモデル つくよみちゃん | 上記の版 | つくよみちゃんコーパスの利用規約 | 配布元から 39.7 MB（このページには置かない）|

- 聞き取りのモデル（`.data`）は GitHub の1ファイル100 MBの上限を超えるため、2つに分けて置き（`sherpa/*.data.part1`・`part2`）、
  Worker で1つに戻して sherpa-onnx に渡している。分け方と大きさ・SHA-256 は `sherpa/manifest.json`。2回目からはキャッシュから読む。
- `vendor/` のファイルは npm の配布物をそのまま置いている（書き換えていない）。

## パソコンでの試験（Claude Code、2026-10-30、Edge・画面なし）

Windows の読み上げ（Haruka）で作った「福岡駅までナビして」の音声を、マイクの代わりに繰り返し流して試した。声のモデルは配布元から実際にダウンロードした。

| 項目 | 結果 |
|---|---|
| 確認音 | 開始・終了が記録に出た（0.50秒）|
| 声のモデルのダウンロード | 39.7 MB を配布元から 6.95秒（SHA-256 一致）。2回目はキャッシュから 0.02秒 |
| 読み上げの準備 | 初回 合計 11.4秒（声のモデル 7.6秒 ＋ 部品の準備 3.7秒）、2回目 3.4秒 |
| 固定文の読み上げ | 声を作る 0.42秒、音の長さ 2.02秒（音の大きさ 最大 0.44）。開始・終了が記録に出た |
| 聞き取りの準備 | 合計 約6秒（182.5 MB）|
| 聞き取り（ずっと聞き続ける）| 繰り返し流した音声を20回以上続けて「福岡駅までナビして」と認識 |
| 話し始めから最初の文字が出るまで | 約0.9〜1.05秒 |
| 話し終わってから最終の文字が確定するまで | 約0.84〜1.22秒 |
| 聞き取った文字の読み上げ | 開始・終了が記録に出た |

画面なしのため、音は耳では確かめていない。iPhone では、マイクを使っている間の再生の音量や鳴る場所（スピーカーか受話口か）が変わることがあるため、実機で確かめる。
